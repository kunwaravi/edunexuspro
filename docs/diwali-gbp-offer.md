## How to publish (owner)

1. Sign in to the Google Business Profile for the existing EduNexus Pro listing.
2. Open **Posts** (or **Add update** / **Offer** depending on the current UI).
3. Choose **Add offer** if available.
   - If Offers are not available for this profile/category, choose **Add update**
     and paste the same description with the CTA link.
4. Paste the title, description, dates, link, and coupon code from above.
5. Add an image if required (use an official EduNexus Pro course banner).
6. Preview the post, then click **Publish**.
7. Copy the published post URL (or take a screenshot) as proof.
8. Report back with the published URL. Until then the status stays
   **NOT PUBLISHED**.

## Boundaries

- Google Maps promotion and website coupon redemption are separate systems.
  The coupon limits are enforced by the EduNexus backend, not by Google.
- Do not promise a lower price than the backend actually charges.
- Do not change the payment destination, UPI ID, or QR code in the post.
